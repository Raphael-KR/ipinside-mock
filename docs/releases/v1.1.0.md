# IPinside Mock v1.1.0

티머니(`https://pay.tmoney.co.kr`)에서 로그인을 막는 TouchEn nxKey 설치 확인에
대응하는 기능을 기존 메뉴바 앱에 추가했습니다.

## 변경 사항

- **TouchEn nxKey · 티머니 → 설치 확인 시작·중지** 메뉴 추가.
- 설치 확인용 로컬 WSS 서버(`127.0.0.1:34581`)와 최소 초기화·준비 응답 구현.
- IPinside와 Python 프로세스 관리·기존 TLS 인증서 재사용.
- 두 기능을 독립적으로 켜고 끄며 앱 종료 시 각각의 자식 프로세스 중지.
- 설치 없이 별도 폴더에 빌드하는 `--no-install`, `--output-dir`, `--sdk` 옵션 추가.

키보드 보호·E2E 암호화·로그인·결제 기능은 구현하지 않습니다. TouchEn 기능에는
IPinside 응답 캡처 데이터가 필요하지 않습니다.

## 다운로드와 설치

- `IPinsideMock-v1.1.0-macos-arm64.zip`: Apple Silicon용 앱.
- `SHA256SUMS.txt`: 다운로드 파일의 SHA-256 체크섬.

ZIP을 풀어 `IPinsideMock.app`을 응용 프로그램 폴더에 복사한 뒤 실행합니다.
`/usr/bin/python3` 실행 환경과 기존 공통 TLS 인증서가 필요합니다.
인증서가 없다면 앱 메뉴의 **공통 인증서 설정…**에서 기존 IPinside 인증서를
복사·신뢰 등록할 수 있습니다.

앱은 ad-hoc 서명이며 Apple 개발자 ID 서명·공증은 없습니다. macOS 보안 정책에 따라
다운로드 앱의 실행이 제한될 수 있습니다. 이 경우 저장소의 소스 빌드를 사용할 수 있습니다.

## 검증 범위

- 개발 단계에서 Swift arm64 빌드, Bash·Python 정적 검사, 번들 리소스 확인을 통과했습니다.
- 사용자가 티머니에서 정상 동작을 확인했다고 보고했습니다. 에이전트가 직접 실행한
  통합 시험 결과와는 구분합니다.
- 릴리스용 버전 1.1.0 빌드, 번들 버전·리소스, ad-hoc 서명 검사를 통과했습니다.
- 배포 ZIP을 다시 풀어 코드 서명을 재검사하고 원본 번들의 모든 파일과 일치함을 확인했습니다.
- 최소 배포 타깃은 macOS 12.0이며, macOS 12 실행과 Intel 바이너리는 검증하지 않았습니다.
- 로그인 완료, 결제, 다른 사이트 호환성과 종료 시 프로세스 정리는 별도 검증하지 않았습니다.
